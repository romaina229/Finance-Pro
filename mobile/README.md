# Mobile — ONG Finance Pro

Dossier réservé à l'application mobile. Techno pas encore choisie entre :

- **React Native** — cohérence de code avec `frontend-web`/`frontend-desktop` (React + TypeScript), partage possible de composants et de logique métier.
- **Flutter** — meilleures performances natives pour le mode offline (accès SQLite, gestion mémoire), UI plus fluide sur bas de gamme Android très répandu en Afrique de l'Ouest.
